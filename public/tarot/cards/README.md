# Rider–Waite–Smith card fronts

This directory contains all 78 card fronts used by the tarot experience. They
are bundled with the frontend so readings do not depend on a third-party image
host at runtime.

The images are resized PNG copies of the 1909 Rider–Waite–Smith deck scans from
[`sixseeds/tarot-api`](https://github.com/sixseeds/tarot-api), where the deck is
identified as public domain. Original artwork by Pamela Colman Smith.
